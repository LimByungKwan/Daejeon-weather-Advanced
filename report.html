05 · 알려진 한계와 미해결 문제

  • tests/browser.test.cjs가 41번째 줄에서 실패했습니다. 인계 전 원본에서도 같은 실패가 보고됐고 원인은 확인하지 못했습니다. 해당 검사는 Actions 범위에 포함되지 않았습니다.
  • 조회 없이 열었을 때 원천 시각이 30분 이내이면 상태 배지와 진단 문구가 다르게 해석될 수 있습니다.
  • 장애 재생 탭의 기존 문구는 이번 변경 범위에서 제외했습니다.
  • 실제 API 호출·실물 휴대폰 확인·자동 API 기반 AI 간 연결은 이번 결과에 포함되지 않습니다.

Actions 성공이 브라우저 검사 전체 통과를 의미하지는 않습니다.
